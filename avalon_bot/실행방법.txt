[1단계] 디스코드 봇 생성 (처음 한 번만)
--------------------------------------------------

1. 브라우저에서 아래 주소로 접속합니다:
   https://discord.com/developers/applications

2. 디스코드 계정으로 로그인합니다.

3. 오른쪽 위 "New Application" 버튼 클릭

4. 이름 입력 (예: "아발롬 봇") → "Create" 클릭

5. 왼쪽 메뉴 "Bot" 클릭

6. "Reset Token" → 토큰 복사 (반드시 저장!)

7. 같은 페이지에서:
   - "MESSAGE CONTENT INTENT" → 켜기 (ON)

8. 왼쪽 메뉴 "OAuth2" 클릭

9. "OAuth2 URL Generator"에서:
   - SCOPES: "bot"과 "applications.commands" 체크
   - BOT PERMISSIONS:
     * Send Messages
     * Embed Links
     * Read Message History
     * Use Slash Commands

10. 생성된 URL로 봇을 서버에 초대


[2단계] 토큰 설정
--------------------------------------------------

1. C:\Users\user\avalon_bot\ 폴더에서
   ".env.example"을 복사하여 ".env" 파일 생성

2. ".env" 파일을 메모장으로 열고:
   DISCORD_TOKEN=여기에_토큰_붙여넣기

   ※ 따옴표 없이 그대로 붙여넣기!
   ※ 토큰은 절대 공유 금지!


[3단계] 라이브러리 설치 (처음 한 번만)
--------------------------------------------------

명령 프롬프트(cmd) 또는 PowerShell에서:

   cd C:\Users\user\avalon_bot
   pip install -r requirements.txt


[4단계] 봇 실행
--------------------------------------------------

   cd C:\Users\user\avalon_bot
   python bot.py

"준비 완료!" 메시지가 나오면 성공!
종료: Ctrl + C


[5단계] 게임 플레이
--------------------------------------------------

1. 디스코드에서 /아발롬 입력

2. 로비:
   [참가]      - 게임 참가
   [퇴장]      - 게임 퇴장
   [AI 추가]   - AI 플레이어 추가 (호스트만)
   [AI 제거]   - AI 플레이어 제거 (호스트만)
   [게임 시작]  - 게임 시작 (호스트만, 5명 이상)

   ※ 혼자 플레이: AI 4명 이상 추가!

3. 게임 흐름:

   밤 → DM으로 역할 확인!
     ↓
   리더가 원정대 편성 (셀렉트 메뉴)
     ↓
   모두가 찬반 투표 (버튼)
     ↓
   승인 → 원정대 퀘스트 수행 (DM으로 비밀 투표)
   거부 → 다음 리더 (5회 연속 거부 = 악 승리)
     ↓
   퀘스트 결과 공개
     ↓
   성공 3개 → 암살자가 멀린 지목 (맞추면 악 역전승!)
   실패 3개 → 악의 승리!

4. 규칙 확인: /아발롬규칙


[게임 규칙 요약]
--------------------------------------------------

■ 진영
  선 (아서 왕): 퀘스트를 성공시켜라!
  악 (모드레드): 퀘스트를 방해하라!

■ 역할
  [선의 진영]
  🧙 멀린    - 악의 정체를 알지만, 들키면 암살당함
  🛡️ 퍼시벌  - 멀린이 누군지 알지만, 모르가나와 구분 불가
  ⚔️ 충신    - 특별한 능력 없음

  [악의 진영]
  🗡️ 암살자  - 마지막에 멀린을 지목 가능
  🧝‍♀️ 모르가나 - 퍼시벌에게 멀린으로 보임
  👤 하수인   - 특별한 능력 없음

■ 인원별 구성
  5명:  선3/악2,  퀘스트 2-3-2-3-3
  6명:  선4/악2,  퀘스트 2-3-4-3-4
  7명:  선4/악3,  퀘스트 2-3-3-4*-4
  8명:  선5/악3,  퀘스트 3-4-4-5*-5
  9명:  선6/악3,  퀘스트 3-4-4-5*-5
  10명: 선6/악4,  퀘스트 3-4-4-5*-5
  (* = 실패 2개 필요)

■ 핵심 규칙
  - 선은 퀘스트에서 "성공"만 낼 수 있음
  - 악은 "성공" 또는 "실패"를 선택 가능
  - 실패 카드가 1개라도 있으면 퀘스트 실패 (* 제외)
  - 5번 연속 원정대 거부 → 악의 자동 승리
  - 선이 3승해도, 암살자가 멀린을 맞추면 악의 역전승!


[DM이 안 올 때]
--------------------------------------------------

디스코드 설정 → 개인정보 및 보안
→ "서버 멤버가 보내는 다이렉트 메시지" 허용

※ DM 실패 시 자동 처리되지만, 역할/퀘스트 정보 확인 불가!


[문제 해결]
--------------------------------------------------

Q: 슬래시 명령어가 안 뜹니다
A: 봇 실행 후 최대 1시간 소요. 봇 재초대 시
   "applications.commands" 권한 확인.

Q: "이미 게임이 진행 중입니다" 오류
A: 봇 종료(Ctrl+C) 후 재실행하면 초기화됩니다.

Q: 투표가 안 됩니다
A: 게임 참가자만 투표할 수 있습니다.
   이미 투표한 경우 중복 불가.
