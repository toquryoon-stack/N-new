==================================================
  덤불쏭 디스코드 봇 - 실행 가이드
==================================================


[1단계] 디스코드 봇 생성 (처음 한 번만)
--------------------------------------------------

1. 브라우저에서 아래 주소로 접속합니다:
   https://discord.com/developers/applications

2. 디스코드 계정으로 로그인합니다.

3. 오른쪽 위 "New Application" 버튼을 클릭합니다.

4. 이름을 입력합니다 (예: "덤불쏭 봇") → "Create" 클릭

5. 왼쪽 메뉴에서 "Bot" 클릭

6. "Reset Token" 버튼을 클릭하여 토큰을 생성합니다.
   ※ 토큰이 표시되면 반드시 복사해두세요! (다시 볼 수 없습니다)

7. 같은 페이지 아래쪽에서 다음 옵션을 확인합니다:
   - "MESSAGE CONTENT INTENT" → 켜기 (ON)

8. 왼쪽 메뉴에서 "OAuth2" 클릭

9. "OAuth2 URL Generator"에서:
   - SCOPES: "bot"과 "applications.commands" 체크
   - BOT PERMISSIONS:
     * Send Messages
     * Embed Links
     * Read Message History
     * Use Slash Commands

10. 생성된 URL을 복사하여 브라우저에 붙여넣기 → 봇을 초대할 서버 선택 → 승인


[2단계] 봇 토큰 설정
--------------------------------------------------

1. 게임 폴더로 이동합니다:
   C:\Users\user\in_a_grove_bot\

2. ".env.example" 파일을 복사하여 ".env" 파일을 만듭니다.
   (또는 메모장으로 새 파일 ".env"를 만듭니다)

3. ".env" 파일을 메모장으로 열어 아래와 같이 수정합니다:

   DISCORD_TOKEN=여기에_복사한_토큰_붙여넣기

   예시:
   DISCORD_TOKEN=여기_부분에_길게_생긴_토큰_문자열이_들어갑니다

   ※ 토큰 앞뒤에 따옴표("") 없이 그대로 붙여넣으세요!
   ※ 토큰은 절대 다른 사람에게 공유하지 마세요!


[3단계] 필요한 프로그램 설치 (처음 한 번만)
--------------------------------------------------

1. Python이 설치되어 있어야 합니다.
   - 설치 확인: 명령 프롬프트(cmd)에서 "python --version" 입력
   - 없으면: https://www.python.org/downloads/ 에서 다운로드

2. 필요한 라이브러리를 설치합니다.
   명령 프롬프트(cmd) 또는 PowerShell을 열고:

   cd C:\Users\user\in_a_grove_bot
   pip install -r requirements.txt

   ※ 이미 설치되어 있으면 이 단계는 건너뛰어도 됩니다.


[4단계] 봇 실행
--------------------------------------------------

1. 명령 프롬프트(cmd) 또는 PowerShell을 엽니다.

2. 게임 폴더로 이동합니다:
   cd C:\Users\user\in_a_grove_bot

3. 봇을 실행합니다:
   python bot.py

4. 아래와 같은 메시지가 나오면 성공입니다:
   "준비 완료! (ID: ...)"
   "...개 서버에 연결됨"

5. 봇을 종료하려면 Ctrl + C 를 누릅니다.

   ※ 봇은 이 창을 켜놓은 동안에만 작동합니다!
   ※ 창을 닫으면 봇도 종료됩니다.


[5단계] 게임 플레이
--------------------------------------------------

1. 디스코드에서 봇이 초대된 서버의 아무 텍스트 채널에 갑니다.

2. 채팅창에 /덤불쏭 을 입력합니다.
   (슬래시 명령어가 자동완성으로 뜹니다)

3. 로비 화면이 나타납니다:

   [참가]     - 게임에 참가합니다
   [퇴장]     - 게임에서 나갑니다
   [AI 추가]  - AI 플레이어를 추가합니다 (호스트만 가능)
   [AI 제거]  - AI 플레이어를 제거합니다 (호스트만 가능)
   [게임 시작] - 게임을 시작합니다 (호스트만, 2명 이상일 때)

   ※ 혼자 플레이하려면 AI를 1명 이상 추가하세요!

4. 게임이 시작되면 자동으로 진행됩니다:

   라운드 시작
     ↓
   타일 확인 (채널의 [내 타일 확인] 버튼 클릭 → 나에게만 보임)
     ↓
   타일 전달 (오른쪽 플레이어에게)
     ↓
   받은 타일 확인 (역시 채널 버튼 → 나에게만 보임)
     ↓
   발견자 수사 (발견자만 채널의 [수사 시작] 버튼 클릭
              → 용의자 2명 확인 + 교체 선택도 나에게만 보임)
     ↓
   고발 (채널에서 버튼으로 용의자 선택)
     ↓
   결과 공개
     ↓
   다음 라운드 또는 게임 종료

   ※ DM을 따로 확인할 필요가 없습니다! 모든 개인 정보는
     디스코드 채널 안에서 버튼을 눌러 "나에게만 보이는 메시지"로
     바로 확인할 수 있습니다.

5. 규칙을 확인하려면: /덤불쏭규칙 입력


[게임 규칙 요약]
--------------------------------------------------

목표: 용의자 3명 중 범인을 맞추세요!

타일:
  - 숫자 1~8 + 빈 타일(X) = 총 9장
  - 5번이 용의자에 없으면 → 가장 높은 숫자 = 범인
  - 5번이 용의자에 있으면 → 가장 낮은 숫자 = 범인
  - 빈 타일은 절대 범인이 될 수 없음

칩 규칙:
  - 시작: 수사 칩 7개
  - 정답: 수사 칩 1개 영구 제거 (좋은 것!)
  - 오답 (아래): 수사 칩 1개 잃음
  - 오답 (맨 위): 수사 칩 1개 잃고 + 스택 전체를 무능 칩으로 받음

패배 조건 (아래 중 하나라도 해당되면 패배):
  - 수사 칩이 0개가 됨
  - 총 칩 (수사 + 무능)이 8개 이상이 됨

승리: 패배하지 않고 총 칩이 가장 적은 플레이어!


[타일 정보가 안 보일 때]
--------------------------------------------------

타일/수사 정보는 DM이 아니라 채널의 버튼을 눌렀을 때
"나에게만 보이는 메시지"로 표시됩니다.

- 버튼을 눌렀는데 아무것도 안 보인다면, 디스코드 화면 하단에
  숨겨진 채로 잠깐 표시되었을 수 있습니다. 다시 버튼을 눌러보세요.
- 버튼이 비활성화되어 있다면 이미 시간이 초과되어 자동으로
  처리된 것입니다 (게임은 계속 진행됩니다).


[문제 해결]
--------------------------------------------------

Q: "DISCORD_TOKEN이 설정되지 않았습니다!" 오류
A: .env 파일에 토큰이 올바르게 입력되었는지 확인하세요.
   파일 이름이 정확히 ".env"인지 확인하세요 (.env.txt가 아님!)

Q: 슬래시 명령어가 안 뜹니다
A: 봇 실행 후 최대 1시간까지 걸릴 수 있습니다.
   서버에서 봇을 제거하고 다시 초대해보세요.
   (초대 시 "applications.commands" 권한을 꼭 체크하세요)

Q: "이 채널에서 이미 게임이 진행 중입니다" 오류
A: 이전 게임이 끝나지 않은 것입니다.
   봇을 종료(Ctrl+C)했다가 다시 실행하면 초기화됩니다.

Q: 봇이 응답하지 않습니다
A: 명령 프롬프트 창이 열려 있는지 확인하세요.
   봇이 실행 중인 창에 에러 메시지가 있는지 확인하세요.
